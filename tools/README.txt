========================================================================
Game Booster PRO v2.0 - Optional Support & Fallback Tools
========================================================================

Normally, you do NOT need any file in this directory. 
Simply double-click `GameBooster.exe` located at the root directory.

Files in this folder:
- `Debug_GameBooster.bat`
  Launches Game Booster in an open PowerShell console window so you can
  view real-time internal logs, initialization timings, and debugging output.

- `Export-DebugReport.bat`
  Collects active hardware states, running gaming services, recent logs,
  and crash traces into a text file saved to your Desktop.

- `Run_GameBooster_Admin.bat`
  A legacy fallback batch launcher with built-in UAC elevation in case your
  Windows security policy prevents launching the .exe directly.
